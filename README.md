# ☕ Ordering System - Pixel-Coffee
An intuitive and fast web-based system designed to streamline order management in the café, allowing customers to place their orders quickly and easily and enabling staff to organize them seamlessly.

## Customer View
A clean, responsive interface optimized for mobile devices and tablets in the coffee shop <br>
The customer's order will be accessible via a QR code available at the store <br>

- As soon as they open the app, customers can choose between placing an order or checking the status of their order. If they choose to place an order, they will be asked to select either “take away” or “eat-in.”
